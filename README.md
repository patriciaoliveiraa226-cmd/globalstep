# GlobalStep — Protótipo de Website

Protótipo académico pronto para GitHub Pages.

Ficheiros: index.html, contactos.html, faqs.html, privacidade.html, termos.html e style.css.

Abrir `index.html` localmente para testar. Para publicar no GitHub: criar um repositório, carregar os ficheiros e ativar Settings → Pages → Deploy from branch → main → /root.

Os elementos entre [ ] são placeholders para os dados legais reais.
